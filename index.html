Under The Hood

How multi-screen distribution works

Sources in, screens out, one managed network between — the same backbone carries video, audio and control.

1 · Encode

A node at each source compresses the feed to ~30 Mbps.

2 · Transport

The PoE switch carries every stream and powers each node over Cat6.

3 · Decode

A node at each screen shows whatever the tablet assigns — instantly.
