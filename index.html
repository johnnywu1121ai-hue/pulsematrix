Core Capabilities

Built for venues that can't afford lag

Every component is engineered for the reliability, scale and cable-simplicity a working commercial floor demands.

Single Cat6 PoE Delivery

One structured cable carries video and power to every encoder and decoder node. No HDMI runs, no power bricks, no wall warts behind the TV.

Tablet Drag-and-Drop Control

Staff route any source to any screen from an iPad or Android tablet, with live video preview thumbnails. Reassign the whole floor between games in seconds.

Zero-Server Reliability

How It Works

Sources in. Screens out. One network in between.

PulseMatrix replaces the fixed matrix switcher with encoder and decoder nodes that live on a managed Gigabit PoE network.

01

Encode at the source

An ENC node sits behind each cable box, streaming box or media player — Rogers, Bell, satellite or Apple TV — compressing 4K@30 / 1080p input into a ~30 Mbps H.265 stream.

02

Transport over PoE

A managed Gigabit PoE switch carries every stream as multicast traffic and powers each node down the same Cat6 cable. Add screens by adding ports — not by rewiring.

03

Decode at the screen

A DEC node behind each TV subscribes to whichever source the tablet assigns and drives the panel over HDMI — instantly re-routable from the control app.

Architecture

Why distributed AVoIP wins the floor

A fixed HDMI matrix locks you into its port count and a spider's web of home-run cable. AVoIP scales on the network you already understand.

Capability Legacy HDMI Matrix + Extenders PulseMatrix Distributed AVoIP
Scalability Fixed to chassis ports (e.g. 8×8, 16×16); replace the whole unit to grow. 1:1 to 100+ endpoints — add a node and a switch port at a time.
Cabling Every display home-runs back to the rack; separate power at each TV. Single Cat6 to the nearest switch; power and video over PoE.
Point of failure Central matrix chassis — if it fails, every screen goes dark. Distributed, zero-server; a single node fault never takes down the floor.
Video walls Needs a separate video-wall processor and dedicated wiring. Native tiling and splitting across any group of decoder nodes.
Control Proprietary remote or wall panel; limited live preview. iOS / Android tablet, drag-and-drop with live video thumbnails.
Distance Extender-limited; long runs need boosters or fibre. Anywhere the network reaches — across floors, patios and buildings.
Expansion cost Step-function: outgrow the chassis, buy a bigger one. Linear: pay per node as the venue grows.
